{% load static %}{% comment %} One range card, shared by the home rail and the Catalogues page. `catalogue` switches on the catalogue behaviour: the card opens a PDF preview instead of navigating, the download button appears, and the title, subtitle and picture come from the category's catalogue fields. Those fall back to the category's own, so a card reads the same until someone overrides it. A catalogue card points at the preview endpoint rather than the category page, so the URL the browser shows on hover is the one the click opens — and without JavaScript the card still reaches the catalogue. Without the flag the card is a plain link to the category page showing the category's own name and picture, which is what the home rail wants. {% endcomment %}
